# 📢 Facebook Ads Practice Campaign

A practical Facebook Ads campaign created using **Meta Ads Manager** as part of a **Digital Marketing Internship**. This project demonstrates the complete process of planning, configuring, and documenting a website traffic campaign for **Tomar Digital Marketing**, an imaginary digital marketing agency.

---

## 📖 About the Project

The purpose of this project was to gain practical experience in creating and managing Facebook advertising campaigns using Meta Ads Manager. The campaign was developed to promote digital marketing services and drive traffic to a business website while applying industry-standard campaign planning techniques.

The project includes campaign planning, audience targeting, budget configuration, ad creative design, campaign preview, and detailed project documentation. Although the campaign remained in **Draft** mode due to the payment method requirement, every stage of campaign creation was successfully completed.

---

## 🎯 Project Objectives

- Understand the Facebook advertising workflow using Meta Ads Manager.
- Create and configure a Website Traffic campaign.
- Define an appropriate target audience based on demographics and interests.
- Configure campaign budget, schedule, and placements.
- Design professional advertisement creatives.
- Gain hands-on experience with Facebook Ads campaign management.
